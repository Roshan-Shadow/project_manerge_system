# 项目管理系统 · 作战驾驶舱（Electron 桌面应用）

依据《PRD_项目管理系统.md》实现的桌面应用：**主页 / 仪表盘 / 甘特图 / 计划 / 需求 / 缺陷 / 模板中心** 七大模块 + **四套可切换主题** + **多系统仓库管理/导入导出/设置**，
作战驾驶舱视觉（深色基底 + 橙红暖金光效 + 玻璃拟态 + 火焰流光/粒子/科技网格地面），
数据层为**内存数组仓库**（无需后端即可完整演示增删改查闭环）。

## 快速开始

```bash
npm install        # 安装依赖（Electron / TypeScript / Monaco / electron-builder）
npm start          # 编译 + 启动 Electron 桌面应用
```

单独构建：`npm run build`（tsc 双配置：主/预加载 → dist/cjs，渲染层 ESM → dist/renderer）

浏览器预览（渲染层自动回退为页内内存仓库，便于快速查看）：

```bash
npm run serve:web  # http://localhost:8613/src/renderer/index.html
```

## 打包分发（在其他机器上使用）

```bash
npm run dist       # 产出 Windows 安装包 + 便携版（输出在 release/ 目录）
npm run dist:dir   # 仅产出免安装目录 release/win-unpacked/
```

产物（x64）：

| 文件 | 说明 |
| --- | --- |
| `release/PMS-Cockpit-Setup-{version}.exe` | NSIS 安装版：双击安装，可选安装目录、创建桌面快捷方式 |
| `release/PMS-Cockpit-Portable-{version}.exe` | 便携版：单文件免安装，拷到任意 Windows 机器双击即用 |

- 打包内容：编译产物（dist/）+ 渲染层（index.html/styles）+ Monaco 编辑器（min/vs）打进 app.asar；
- 主题等 UI 偏好经 localStorage 记忆；**业务数据为内存仓库，每次启动均为空列表初始态**（符合交付约束）；
- 未做代码签名：其他机器首次运行可能弹出 SmartScreen/未知发布者提示，选「仍要运行/更多信息→仍要运行」即可；
- 网络受限环境下若 NSIS 工具链下载失败，使用镜像重试：
  `ELECTRON_BUILDER_BINARIES_MIRROR=https://npmmirror.com/mirrors/electron-builder-binaries/ npm run dist`
- 自定义图标：放置 `build/icon.ico`（≥256x256）后，删除 package.json `build.win` 中的 `"signAndEditExecutable": false` 重新打包（该配置用于跳过 exe 元数据编辑工具链）。

> 内存仓库不落盘：刷新/重启后数据回到空列表初始态（符合「默认空列表、无预置假数据」交付约束）。

## 技术架构

- **Electron 多进程**：主进程持有内存数组仓库并注册 IPC Handler（`src/main`）；
  preload 以 contextBridge 暴露类型安全 API（contextIsolation 开启，`src/preload`）；
  渲染进程为纯 ESM 前端（`src/renderer`）。浏览器预览时渲染层自动降级为页内仓库，同一套 `shared/storeOps.ts` 纯函数。
- **TypeScript 双编译目标** + **Monaco 编辑器**（模板中心结构定制，加载失败自动降级 textarea）。
  Monaco 资源在构建时由 `tools/sync-monaco.mjs` 内置到 `src/renderer/assets/monaco/vs`（electron-builder 会剥离 node_modules 中的 devDependencies，不能直接引用）。
- **多主题**：`core/theme.ts` 六套主题定义，CSS 自定义属性（`body[data-theme]`）全量换色，Canvas 图表/粒子/Monaco 按主题取色，localStorage 记忆偏好。
- **多系统仓库**：支持创建多个系统仓库对不同项目分类管理，切换仓库时自动加载对应项目数据。
- 分层：`shared`（类型/日期/仓库纯函数/内置模板）→ `main / preload`（设置/仓库/IPC）→ `renderer/core`（状态、DOM、表单校验、特效、主题）→ `renderer/modules`（主页/仪表盘等业务模块）。

## 测试流程（交付必读）

打开应用后按以下顺序操作，可完整走通数据闭环：

### 0. 主页（默认首页，PRD §3.9）
- 所有项目的「项目概况」卡片墙：状态、周期、完成率、任务数、延期数、下一任务截止；
- **三种排序**：按创建时间 / 按下一任务截止（无未完成任务排末尾）/ 按最终完成时间，可切换升/降序；
- 点击卡片（或【进入项目 →】）切换当前项目并跳转仪表盘；卡片上可直接【📁 仓库】【⇩ 快照】。

### 0.5 系统仓库管理（PRD §3.10）
- **多仓库支持**：支持创建多个系统仓库，对不同项目进行分类管理；
- **切换仓库**：点击头部【管理仓库】或设置中的【切换系统仓库】，选择目标仓库即可切换；
- **切换逻辑**：切换仓库时自动清空内存数据，加载目标仓库的项目数据，确保仓库间数据隔离；
- **首次启动向导**：首次打开（无工作目录记录）会弹出向导，选择工作目录或创建新仓库；
- **设置保存于 `<工作目录>/setting.json`**（随工作目录整体迁移）；工作目录下自动维护 `repos`（项目仓库）/ `cache` / `temp` / `plugins`；
- 浏览器预览无文件系统，向导与文件功能仅桌面版。

### 1. 新建项目（列表初始为空）
1. 首次打开显示「暂无项目」空状态；点击右上角 **【＋ 新建项目】**；
2. 选择模板（如 *软件研发迭代*），填写项目名称、负责人、起止日期、成员（逗号分隔）；
3. 直接点「创建项目」不填内容 → 可见**必填校验**红字提示；填写完整后创建；
4. 系统按模板生成阶段和任务（阶段切分与任务排期按项目周期映射）。

### 2. 计划（任务 / 阶段 / 交付物 / 用时 / 文件提交）
- **新增**：【＋ 新增任务】→ 填标题/负责人/日期（校验：必填、结束≥开始）→ 创建后列表自动刷新；
- **编辑**：行内「编辑」→ 可改字段；弹窗底部「交付物 / 提交模块」可添加交付物（名称+说明）、确认接收、删除；
- **状态流转**：行内状态下拉一键切换（进行中自动记录用时起点、已完成记录完成日期，驱动仪表盘折线与用时统计）；
- **用时统计**：任务栏「用时」列 = 首次进入「进行中」到「已完成」的时长，进行中实时累计；回到「待开始」重置计时；
- **提交文件**：任务栏【提交】→ 多选文件 → 复制保存到该任务的仓库文件夹（阶段/任务 层级，重名自动加序号），并自动登记为交付物（含保存路径）；
- **文件夹跳转**：任务栏与阶段分组行的 📁 按钮 → 在资源管理器中打开对应层级文件夹（不存在则先创建）；
- **阶段选择框**：阶段行前有选择框，勾选后自动选中该阶段下所有任务，支持批量删除；
- **全选/取消全选**：表头选择框可一键选中或取消所有阶段和任务；
- **批量删除**：勾选多个阶段/任务 → 点击批量删除按钮 → 确认后删除（阶段删除时该阶段下任务一并删除）；
- 阶段管理：【＋ 阶段】新增，分组行内 编辑 / 删除 / 📁。

### 3. 需求 / 缺陷
- 需求：【＋ 新增需求】→ 可勾选**关联任务**（需求拆解）；行内状态流转；关联任务数 chip 可查看进度明细；
- 缺陷：【＋ 登记缺陷】→ 严重程度决定 SLA（致命1/严重2/一般4/轻微7 天），超期行红色「超期 n 天」脉冲提醒。

### 4. 甘特图
- 日/周/月视图切换；负责人/状态筛选；**拖拽任务条整体平移排期、拖右缘调整工期**；点击任务条打开编辑；
- 今日金线。

### 5. 仪表盘（数据实时聚合）
- 指标卡片（透视图标，点击展开明细）、环形完成度、计划 vs 实际双条、近 30 天完成任务/新增缺陷折线（游标光点流动）、
  优先级看板、成员×阶段负载热力（面板标题「⤢ 展开」为 320ms 宽高插值）、风险告警日历（红=已延期 / 金=3天内到期，点击日期看明细）。

### 6. 任务延期提醒（站内）
- 右上角铃铛：延期任务自动分级为「已延期 / 高风险（>3天）」，到期前 3 天/当天提示；未读角标、点击已读、全部已读。

### 7. 模板中心
- 内置 4 个系统模板（可「使用」创建项目，也可直接【编辑】调整结构或【复制】为自定义模板）：**软件研发迭代 / 产品发布 / 日常运营项目 / 论文撰写**；
- **模板提示词**：每个阶段有 `phases_tip`（阶段AI辅助提示），每个任务有 `task_tip`（任务AI辅助提示）；
- 系统模板编辑作用于本次会话（重启恢复默认），如需长期定制请【复制】为自定义模板后编辑；
- **⇪ 保存当前项目为模板**（结构快照：阶段 + 任务清单 + 提示词）；
- 自定义模板：编辑（Monaco JSON 编辑器，含结构校验）、复制、重命名、删除；
- 编辑后通过「使用」创建新项目即可复用定制结构。

### 8. 主题更换（PRD §8.3）
- 头部【主题】按钮（显示当前主题名）打开下拉：**熔金战情**（默认）/ **深海蓝讯** / **翡翠方舟** / **曙光白域**（浅色）/ **暮霭柔光**（浅色）/ **晴空素笺**（浅色）；
- 点击即时生效：玻璃面板、发光标题、火焰流光、粒子光点、科技网格、Canvas 图表（环形/折线/优先级/热力）、甘特图任务条与今日线、Monaco 编辑器明暗配色全部联动换色；
- 主题偏好写入 localStorage 记忆，刷新 / 重启后保持；语义色（成功/告警/错误、延期红/临期金）跨主题一致。

### 9. 项目仓库与导入导出（PRD §3.8，桌面版）
- **自动仓库**：新建项目后自动在 `<工作目录>/repos/<项目目录>` 创建仓库；**层级为「阶段（父文件夹）→ 任务（子文件夹）」**：各阶段文件夹同级置于仓库根，任务归入其所属阶段（未分组任务的文件夹置于仓库根，同名任务自动加短ID）；
- **project.json 状态档案**：仓库根目录的 `project.json` 持续记录项目状态——完整数据快照（项目/阶段/任务/需求/缺陷）+ 仓库目录结构 + 生成时间，随数据变更自动刷新（防抖）；阶段增删改自动同步子目录（**只增不删**，已存文件安全）；项目重命名自动迁移目录；
- **导出**：仪表盘概况卡【⇩ 导出快照】→ 另存单个 `.json` 迁移文件；
- **导入**：头部【⇪ 导入项目】→ 选择迁移文件 → 项目及全部子数据完整恢复（新 ID、关联关系保持），同名自动加「（导入）」后缀，并重建仓库目录；
- **打开仓库**：概况卡【📁 打开仓库】在资源管理器中打开项目目录；
- 浏览器预览（内存模式）无文件系统，以上入口会给出提示。

### 10. 整体导入（计划模块）
- **使用模板**：选择模板中心的模板快速创建计划结构，模板的阶段提示和任务提示会自动填充；
- **选择JSON文件**：支持导入 `.json` 格式的计划文件；
- **制定计划框**：支持手动输入或粘贴 JSON 格式的计划数据，带行号显示和格式校验；
- **底部操作**：格式化（美化 JSON）+ 导入（执行导入）+ 取消。

## 约束符合性

| 强制项 | 落实 |
| --- | --- |
| 默认空列表，无预置假数据 | 所有业务列表初始为空，必须经【新增】表单提交才产生数据（内置模板为系统配置项） |
| 完整 CRUD | 新增/编辑/单行删除/批量删除/必填校验/提交自动刷新 全部实现 |
| 无死组件 | 所有按钮/弹窗/下拉/复选框均绑定事件；弹窗支持 ✕ / 遮罩 / Esc 关闭 |
| 内存数组存储 | 主进程内存数组（浏览器预览为页内数组），无后端自闭环 |
| 不做需求外组件 | 页面结构对齐 PRD 模块，无额外菜单 |

## 目录结构

```
├── PRD_项目管理系统.md      # 产品需求文档（含视觉/动画/架构规范）
├── tools/serve.mjs          # 浏览器预览静态服务器
├── src/
│   ├── shared/              # 类型 / IPC 通道 / 内存仓库纯函数 / 内置模板
│   ├── main/                # Electron 主进程 + IPC Handler
│   ├── preload/             # contextBridge 桥
│   └── renderer/
│       ├── index.html / styles/
│       ├── core/            # 状态 / DOM / 表单校验 / 特效 / 应用编排
│       └── modules/         # dashboard / gantt / plan / requirement / bug / template
└── dist/                    # 编译产物（cjs + renderer ESM）
```
